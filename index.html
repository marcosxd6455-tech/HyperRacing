Descripción General del Videojuego:

Finalidad del Videojuego:

El objetivo principal de este proyecto es facilitar el proceso de aprendizaje y asi estimular el desarrollo integral, y fomentar la motivación a través de divesión, donde el estudiante deje de ser un receptor pasivo y se convierta en el protagonista de su propio aprendizaje. El videojuego busca eliminar la barrera de la ansiedad matemática y el miedo a la práctica del segundo idioma, proporcionando un entorno seguro donde el error es parte del ciclo de retroalimentación. A través de retos progresivos, el juego pretende fomentar la autonomía, el pensamiento crítico y la retención de conceptos a largo plazo, asegurando que los usuarios no solo memoricen datos, sino que comprendan la aplicación práctica de lo aprendido.


¿Qué aprendizaje busca reforzar?

El videojuego se centra en un modelo de aprendizaje significativo y procedimental, enfocándose específicamente en: Refuerzo Cognitivo en Matemáticas: Estimulación de la agilidad mental mediante la resolución de operaciones básicas, lógica matemática y reconocimiento de patrones. Se busca fortalecer la capacidad de cálculo rápido y la resolución de problemas aplicados. Adquisición Lingüística (Inglés Nivel A1): Según el Marco Común Europeo de Referencia (MCER), el juego refuerza el aprendizaje de vocabulario esencial, estructuras gramaticales básicas (presente simple, pronombres) y comprensión lectora elemental. Aprendizaje Basado en Problemas (ABP): El usuario debe aplicar sus conocimientos para superar obstáculos dentro de la narrativa del juego, lo que garantiza una conexión directa entre la teoría y la ejecución.


Nivel Educativo:

El videojuego está diseñado específicamente para estudiantes de Primaria Alta, generalmente comprendida entre 4, 5 y 6 grado, con edades de entre 9 y 12 años. En esta etapa evolutiva, los niños desarrollan un pensamiento más abstracto y una mayor capacidad de concentración, lo que permite introducir mecánicas de juego más complejas. El diseño visual y los niveles de dificultad están calibrados para mantener el interés de este rango de edad, utilizando un lenguaje claro pero estimulante que se alinea con las competencias pedagógicas requeridas para el cierre del ciclo primario.


Funcionamiento del Sistema:

¿Cómo inicia el Programa?

El programa inicia realizando un proceso de validación y respuesta, también una mecánica de avance y velocidad y un sistema de gestión de intentos, el cual se dividirá en tres intentos, el primer intento se basa en que si el usuario falla, el juego le permitirá volver a intentarlo sin recibir una penalización alguna. El segundo intento se basa en que, si vuelve a fallar, el sistema muestra una “pista educativa”, el tercer intento si de nuevo se encuentra un error, el programa revela la respuesta correcta para que el usuario lo asimile y pueda continuar la carrera.


¿Cómo interactúa el usuario con el programa?

Cuando el usuario deberá responder los problemas o preguntas que el videojuego le mostrará en pantalla


¿Cómo se desarrolla el videojuego?

El video juego comienza con una fase de preparación donde se debe cargar los recursos como puede ser la pista y el auto, luego va la interacción con el usuario, dónde se le presentará una problema u operación de matemática o inglés, el cuál el alumno debe responder e ingresar su respuesta


¿Cómo finaliza el videojuego?

· ¿Cómo finaliza? Finaliza cuándo el usuario termina de realizar una serie de problemas el cuál se divide en niveles que se dificultará conforme el alumno vaya subiendo de nivel
